## Protocol

Every `Message.hpp` type number is present in `command.rs`. OpenGridder-only types 140, 141, and 142 are not. Reply socket: request replies use command-out (the old `m_cmdIn`). Async pushes use command-in (the old `m_cmdOut`). When the four sockets connect, the worker writes the plugin list on the command socket. Command-in carries KEY, ParameterGesture, ParameterValue, PluginStatus, and HidePlugin when the editor close box is pressed. A client HidePlugin is not echoed. Rescan and Restart close the worker. CPULoad replies on the command socket with the host percent.
