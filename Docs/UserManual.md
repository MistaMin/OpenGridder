# OpenGridder 1.0 BETA - User Manual

The full illustrated manual, with screenshots, is **[OpenGridder-Manual.html](OpenGridder-Manual.html)**. Open it in any web browser. To get a PDF, use the browser's Print command and choose Save as PDF.

It covers installing, starting the server, using OpenGridder in your DAW, the plugin window, latency profiles, drive and oversampling, meters, bouncing, the Plugin Manager, using a second computer, Pro Tools control surfaces and troubleshooting.

## Quick start

1. Quit your DAW and run the `.pkg` installer.
2. Open **OpenGridder Server** from the Applications folder.
3. Insert **OpenGridder** on a track in your DAW and click **+ Add Plugin...**.
